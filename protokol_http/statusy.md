# 1XX: informacyjne
Ta klasa wskazuje, że serwer otrzymał żądanie HTTP wysłane przez przeglądarkę i będzie kontynuował proces.

# 2XX:  Sukces 
Informują o pomyślnym przetworzeniu żądania.

# 3XX: Przekierowania
Oznaczają konieczność dalszych działań w celu ukończenia żądania.

# 4XX: Błędy po stronie klienta
Wskazują, że problem leży po stronie użytkownika lub przeglądarki.

# 5XX: Błędy serwera
Sygnalizują problemy po stronie serwera.
